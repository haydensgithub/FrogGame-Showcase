# My Role

## Overview

I was the project lead for the team. I was responsible for assembling what became the final team of three, directing them, and carrying out most work within Unreal Engine.
I filled this role for over six months, the approximate length of development.

## Team Structure

* Project lead / programming / animation / sound / implementation: Hayden Brimage
* 3D modeling, texturing, level assembly: Juuso Hirvonen
* Concept art and visual design: Mikael Rantanen

## Programming Responsibilities

I personally programmed all systems within the game, including:
* Player movement
* Combat systems
* Enemy behavior
* Save system
* Menus / UI wrappers
* Gameplay state management
* Animation-facing state
* Interaction systems
* Debug/testing tools

## Audio-Visual Responsibilities

My responsibilities in audiovisual development included:
* Rigging and animating of 3D models
* Implementation of 3D rigs in Unreal Engine
* Connecting gameplay states to animation behavior
* Sound effect design
* Sound cue integration
* Particle system design and implementation

## Leadership Responsibilities

In practice, project leadership was much more than taking on central development. My responsibilites also included:
* Setting project direction
* Defining scope
* Coordinating tasks
* Reviewing implementation needs
* Communicating with art team members
* Turning concept art/models into usable in-game assets
* Project promotion
* Making final calls on gameplay/art direction
* Coordinating asset needs between gameplay, concept art, and 3D modeling

## What This Project Demonstrates

This project displays my ability to not only work well within a team, but to manage and coordinate the ideas of those around me. In summary, I have:
* Led a small team
* Built gameplay systems in Unreal Engine
* Integrated art, animation, sound, and code
* Worked across disciplines
* Brought a complex project to a polished vertical-slice state
